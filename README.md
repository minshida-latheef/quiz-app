# 🧠 Quiz App

An interactive and user-friendly Quiz Application built using HTML, CSS, and JavaScript. It allows users to answer multiple-choice questions, test their knowledge, and view their scores instantly.

## 📌 About the Project

The Quiz App is a frontend web application designed to make learning fun and engaging.

Users can participate in quizzes, select answers from multiple options, navigate through questions, and check their final scores at the end of the quiz.

## ✨ Features

- 📝 Multiple-choice questions
- 🎯 Interactive answer selection
- ➡️ Next question navigation
- 📊 Automatic score calculation
- 🏆 Display final quiz results
- 🔄 Restart quiz functionality
- 🎨 Clean and attractive user interface
- 📱 Responsive design

## 🛠️ Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling and layout
- **JavaScript** – Quiz logic and functionality
